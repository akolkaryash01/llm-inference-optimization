API Documentation
POST /generate Generate text, with optional caching 
// Request body
{
  "prompt": "What is gradient descent?",
  "max_tokens": 100,
  "temperature": 0.7,
  "use_cache": true
}

// Response
{
  "response": "Gradient descent is...",
  "latency_ms": 8420,
  "tokens_per_sec": 5.5,
  "tokens_generated": 47,
  "cached": false
}
POST /stream Server-Sent Events token streaming 
// Returns SSE stream
data: {"token": "Gradient"}
data: {"token": " descent"}
data: {"token": " is"}
...
data: [DONE]

// Python client
import requests
with requests.post("/stream", json={"prompt":"..."}, stream=True) as r:
    for chunk in r.iter_content():
        print(chunk.decode(), end="")
